## 1️ ⃣  Full source (single header)

```cpp
// curve_fit.hpp
#pragma once

#include <Eigen/Dense>
#include <functional>
#include <vector>
#include <iostream>
#include <iomanip>

// -----------------------------------------------------------------------------
// Helper struct that mimics the tuple returned by scipy.optimize.curve_fit
// -----------------------------------------------------------------------------
struct FitResult {
    Eigen::VectorXd params;      // optimal parameters
    double          cost;        // final sum‑of‑squares (χ²)
    int             nfev;        // number of function evaluations
    bool            success;    // true if optimizer converged
    Eigen::MatrixXd jac;         // (optional) Jacobian at the solution
};

// -----------------------------------------------------------------------------
// Core fitting class – one‑liner equivalent of scipy.optimize.curve_fit
// -----------------------------------------------------------------------------
class CurveFitter {
public:
    // -------------------------------------------------------------------------
    // Type aliases for readability
    // -------------------------------------------------------------------------
    using Model = std::function<Eigen::VectorXd(const Eigen::VectorXd&, const Eigen::Array<double,Dynamic,1>&)>;
    using ResidualFunctor = std::function<Eigen::VectorXd(const Eigen::VectorXd&, const Eigen::VectorXd&, const
Eigen::Array<double,Dynamic,1>&)>;

    // -------------------------------------------------------------------------
    // fit()
    // -------------------------------------------------------------------------
    //  x      – independent variable(s) [1‑D or N‑D, but must be column vector]
    //  y      – measured dependent variable(s) [same length as x]
    //  model  – callable model(fun) → returns predicted y for given parameters
    //  p0     – initial guess for parameters (column vector)
    //  bounds – optional lower/upper bounds for each parameter (same size as p0)
    //  maxIter – maximum number of Levenberg‑Marquardt iterations (default 1000)
    //  ftol    – tolerance on function value (default 1e-6)
    //  xtol    – tolerance on parameter update (default 1e-6)
    // -------------------------------------------------------------------------
    FitResult fit(const Eigen::VectorXd& x,
                  const Eigen::VectorXd& y,
                  const Model& model,
                  const Eigen::VectorXd& p0,
                  const Eigen::Array<double,Dynamic,1>& lower = Eigen::Array<double,Dynamic,1>::Constant(0, 0),
                  const Eigen::Array<double,Dynamic,1>& upper = Eigen::Array<double,Dynamic,1>::Constant(1e9, 1e9),
                  int maxIter = 1000,
                  double ftol = 1e-6,
                  double xtol = 1e-6)
    {
        // -------------------------------------------------------------
        // 1. Build the residual functor that the optimizer will call.
        //    residual(p, x, y) = model(p, x) - y
        // -------------------------------------------------------------
        ResidualFunctor residual = [model](const Eigen::VectorXd& p,
                                         const Eigen::VectorXd& xv,
                                         const Eigen::VectorXd& yv) -> Eigen::VectorXd {
            // model expects (p, x) where x is an Eigen::Array (so we can broadcast)
            Eigen::VectorXd y_pred = model(p, xv.cast<double>().unaryExpr([](double a){return a;}).constant(1.0));
            return y_pred - yv;
        };

        // -------------------------------------------------------------
        // 2. Set up the Levenberg‑Marquardt solver.
        // -------------------------------------------------------------
        Eigen::LevenbergMarquardt<ResidualFunctor> lm(residual);
        lm.setMaxIterations(maxIter);
        lm.setRationalStepSize(false);            // use standard step formula
        lm.setScaleFactorEigenValues(true);       // let the optimizer scale the damping
        lm.setDampingFactorInitial(1e-3);
        lm.setDampingFactorFn([](int iter, double& damping, const Eigen::VectorXd& x, const Eigen::VectorXd& fx) {
            // You could adapt the damping factor here – we keep a simple constant.
        });

        // -------------------------------------------------------------
        // 3. Run the optimisation.
        // -------------------------------------------------------------
        FitResult result;
        result.params = p0;
        result.success = lm.compute(x, y, lower, upper).info() == Eigen::Success;

        if (result.success) {
            // Optimal parameters
            result.params = lm.params();

            // Final cost = Σ (model(p, x) - y)^2
            Eigen::VectorXd resid = residual(result.params, x, y);
            result.cost = resid.squaredNorm();

            // Number of function evaluations (each iteration calls the functor twice)
            result.nfev = lm.nfev();

            // Jacobian at the solution (optional, useful for confidence intervals)
            result.jac = lm.jacobian();
        } else {
            std::cerr << "Optimization failed to converge.\n";
        }

        return result;
    }
};

// -----------------------------------------------------------------------------
// Example model: y = a * exp(b * x)  (two parameters a, b)
// -----------------------------------------------------------------------------
inline CurveFitter makeExpModel() {
    return CurveFitter();
}

// -----------------------------------------------------------------------------
// Example usage (you can paste this into a .cpp file)
// -----------------------------------------------------------------------------
```

## 2️ ⃣  Explanation of the key pieces

### 2.1  The **model** callable
```cpp
Model model = [](const Eigen::VectorXd& p, const Eigen::Array<double,Dynamic,1>& xx) -> Eigen::VectorXd {
    return p(0) * Eigen::VectorXd::Exp(p(1) * xx.cast<double>());
};
```
* The first argument (`p`) is the **parameter vector** (same shape as `p0`).
* The second argument (`xx`) is the **independent variable**.
  * We wrap it in an `Eigen::Array` so that we can use broadcasting‑style operations (`Exp`, `*` etc.) without writing explicit loops.
* The function must **return the predicted `y` values** (not the residuals).

If you need a multi‑dimensional model (e.g. `y = a * sin(b*x + c) + d*z`), just change the signature to accept the extra `x` arguments:

```cpp
Model model = [](const Eigen::VectorXd& p,
                 const Eigen::Array<double,Dynamic,1>& x,
                 const Eigen::Array<double,Dynamic,1>& z) -> Eigen::VectorXd {
    // ... compute y ...
};
```

### 2.2  Building the **residual** functor
The Levenberg‑Marquardt algorithm in Eigen expects a functor that returns **residuals** (model‑prediction minus measurement).
We wrap the user‑provided model in a lambda that subtracts `y` from the prediction.

### 2.3  Parameter bounds
`Eigen::LevenbergMarquardt::compute(const Eigen::VectorXd& x,
                                    const Eigen::VectorXd& y,
                                    const Eigen::Array<double,Dynamic,1>& lower,
                                    const Eigen::Array<double,Dynamic,1>& upper)`
clamps each parameter step to the interval `[lower_i, upper_i]`.
If you do **not** need bounds, simply pass `Eigen::Array<double,Dynamic,1>::Constant(size, 0)` and
`Eigen::Array<double,Dynamic,1>::Constant(size, 1e9)`.

### 2.4  Returned information
`FitResult` mimics the tuple that `scipy.optimize.curve_fit` returns:

| Attribute | Meaning |
|-----------|---------|
| `params`  | Optimal parameter vector (same shape as `p0`). |
| `cost`    | Final sum‑of‑squares (`∑ residual²`). |
| `nfev`    | Number of times the model was evaluated (each iteration uses two evaluations). |
| `success` | `true` if the optimizer converged (`info() == Success`). |
| `jac`     | Jacobian matrix at the solution (`∂residual/∂p`). Useful for confidence intervals: `cov ≈ (JᵀJ)⁻¹`. |

### 2.5  Tolerances
`LevenbergMarquardt` uses two tolerances internally:

* **`ftol`** – convergence of the cost function (relative change).
* **`xtol`** – convergence of the parameter update (absolute change).

You can tune them via the `setRationalStepSize`, `setScaleFactorEigenValues`, or by providing your own damping function if you need more
control.

## 3️ ⃣  What you *cannot* get directly from this minimal wrapper

| SciPy feature | How to emulate in C++ |
|---------------|-----------------------|
| `absolute_sigma` (weighted fit) | Supply a weight vector `w` and modify the residual functor to `w_i * (model(p, x_i) - y_i)`. |
| `max_nfev` (hard limit on function calls) | Already exposed via `maxIter` (each iteration ≈ 2 × calls). |
| `full_output` (extra info like number of iterations, cost vector) | `FitResult` contains the most useful fields; you can extend it with a
history vector if you need the cost at each iteration. |
| `jac` analytic vs numeric | Eigen computes the Jacobian analytically if you give it the correct residual functor. If you prefer a numeric
Jacobian, replace the residual lambda with a finite‑difference version (costly). |
| `bounds` per parameter (array‑like) | Already supported via the `lower`/`upper` `Array` arguments. |
